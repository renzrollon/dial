# Tasks

Shape: TDD. The change is about two pure transforms with a pass/fail core, the normalisation of a forge list and the readiness verdict, so section 1 writes their failing tests and the tests of the list step, the context document and the skill text, and section 2 makes them green. Section 3 is one whole-suite check. `## H0.` and `## H1.` hold the steps only a person can take; their lines carry `[human]` or `[manual]` in place of a checkbox, so neither OpenSpec nor ship tracks them.

Known test pins this change alters, each updated in the section 1 task that names it: the command list in `test/cli.test.mjs:17-22` (nineteen, now twenty); the cap count in `test/limits.test.mjs:8,22,31,84` (ten, now thirteen); the skill list and pack list in `test/plugin.test.mjs:59,95`; and the forge call counts of a remote sync in `test/remote.test.mjs:39,92,130,149` and `test/sync.test.mjs:503,521,525,528,537` (a complete fetch now makes one more call; a dry run and a failed fetch do not). The rule for any further pin: an assertion that pins a meaning the delta specs change is updated in the task that changes that meaning, never during a remediation stage, and the update names the assertion and the requirement it now pins.

Shared value: the remote cache file `$DIAL_HOME/cache/remote/<repo>.json`, which gains `prs` and `prsError`. Its writer is `remoteFacts` (2.4). Its readers: `remoteFacts` and `dueRemote` in `lib/remote.mjs`, which ignore keys they do not know (asserted in 1.2, design §The cache gains two optional keys; D11), and the new `openPullRequests` (2.4). `lib/collect.mjs`, `lib/next.mjs`, `lib/brief.mjs` and `lib/sync.mjs` reach the cache only through `remoteFacts` and have no task. Second shared value: the check roll-up rule, moved into `lib/sources/forge.mjs` (2.2) and read by `describeGithub` (2.2) and `readiness` (2.3).
