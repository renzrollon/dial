# Tasks

Shape: TDD. The change is about four pass/fail cores: cutting a reply into sentences, turning the session's event stream into effects, the request guard, and the turn and restart rules of the session. Section 1 writes their failing tests, one suite per task, together with the tests of the runner, the speaker, the server, the command, the caps, the page and the prompt, and section 2 makes them green. Section 3 is one whole-suite check. `## H0.` and `## H1.` hold the steps only a person can take; their lines carry `[human]` or `[manual]` in place of a checkbox, so neither OpenSpec nor ship tracks them.

Known test pins this change alters, each updated in the section 1 task that names it: the command list in `test/cli.test.mjs:17-22` (twenty, now twenty-one, `voice` after `watch`); the cap count in `test/cli.test.mjs:231,254-291` (`THIRTEEN_CAPS` and `lines.length, 13`, now sixteen) and in `test/limits.test.mjs:8,22-26,33,45,49-52,59,86,95,120-121` (`THIRTEEN` and "the other twelve", now sixteen and fifteen); and the pack list in `test/plugin.test.mjs:131-136`, which gains the five `lib/voice/` assets. The rule for any further pin: an assertion that pins a meaning the delta specs change is updated in the task that changes that meaning, never during a remediation stage, and the update names the assertion and the requirement it now pins.

Shared values. `LIMITS` in `lib/limits.mjs` gains three keys at the end (2.1); its readers (`lib/agent.mjs`, `brief.mjs`, `collect.mjs`, `context.mjs`, `derive.mjs`, `narrate.mjs`, `next.mjs`, `record.mjs`, `remote.mjs`) read caps by name and have no task; the two places that enumerate every cap are the pins above. The child handle of `lib/spawn.mjs` (design §13 Interfaces) is written by 2.2 and read by the session manager (2.5), the speaker (2.6), the opener in the server (2.9) and `fakeSpawn` in `test/helpers.mjs` (1.4). The event names and payloads of `GET /events` are written by the server (2.9) and read by `lib/voice/page-logic.mjs` (2.8); both take them from the `voice` delta. Every export a test imports is named in design §13 Interfaces; a task that needs another shape changes the design and the test in the same task and says so.

Sockets. Binding a loopback port is refused with `EPERM` inside the Claude Code sandbox. A test that needs a real socket asks `listenLoopback` first and skips with the reason `loopback bind refused (EPERM)` when it answers `{ ok: false, code: 'EPERM' }`. Every other test runs without a socket. H1.1 runs the suite once where binding is allowed.
